# ⚖️ MEEZAN | منصة ميزان لتحليل الموازنات والبلاغات الذكية

> ربط المواطن بالموازنة العامة والمشروعات الحكومية، وتحويل شكاوى المواطنين إلى بيانات حقيقية (Data-Driven Decisions) تدعم صانعي القرار.

---

## 💡 فكرة المشروع (Project Overview)
يُعد **MEEZAN** نظاماً متكاملاً يهدف إلى تعزيز الشفافية والمشاركة المجتمعية عبر إتاحة الفرصة للمواطنين لاستعراض موازنات محافظاتهم والمشروعات الجارية فيها. كما يتيح للمواطنين الإبلاغ عن أي مشكلات أو أعطال (مثل الطرق ومشاكل المياه) عبر نظام ذكي يعتمد على تقنيات الذكاء الاصطناعي (AI) لتصنيف البلاغات وتحديد أولوياتها، مع توفير لوحة تحكم متقدمة للمسؤولين لتحويل هذه الشكاوى إلى بيانات ورؤى توجيهية للموارد.

---

## 🛠️ المكونات الرئيسية للمنصة (Key Components)
1. **لوحة تحليلات الموازنة العامة (`index.html`):**
   - مؤشرات تنفيذية ورسوم بيانية تفاعلية (مدعومة بـ Chart.js) لتحليل الإيرادات، المصروفات، فوائد الديون، وهيكل الإنفاق بمرور السنوات.
2. **بوابة المواطن للبلاغات الذكية (`meezan.html`):**
   - تصفح مشروعات وموازنات المحافظات.
   - نموذج إرسال بلاغات مع محاكاة للذكاء الاصطناعي لتصنيف المشكلة وتحديد درجة خطورتها فوراً.
3. **لوحة تحكم المسؤول وصانع القرار (`admin.html`):**
   - متابعة البلاغات الواردة، معرفة أكثر القطاعات شكاوى، تحديد أعلى المناطق احتياجاً للموارد، وتقديم توصيات مدعومة بالبيانات (Data-Driven Insights).

---

## 🚀 التقنيات المستخدمة (Tech Stack)
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Chart.js
- **Styling & UI:** Responsive Grid Systems, Modern CSS Variables, Google Fonts (Cairo)
- **Deployment:** GitHub Pages
